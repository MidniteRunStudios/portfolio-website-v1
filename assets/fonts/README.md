Place your font files in this folder and reference them from `assets/css/styles.css`.

Recommended formats: `.woff2` (preferred), `.woff`, then `.ttf`.

Example filenames:
- YourCustomFont.woff2
- YourCustomFont.woff

After adding files, update the `src` paths in the `@font-face` rules inside `assets/css/styles.css` if necessary.
